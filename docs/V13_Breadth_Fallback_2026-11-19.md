# V13 prospective NSE breadth fallback, 19 November 2026

The 18 November collection was initially constrained by missing source-day daily prices. A public alternative, TejHQ's adjusted dataset, provided 2,618 exact ISIN, symbol, series, OHLC and volume matches to the original NSE 18 November session file. In six previously affected examples, 215 overlapping adjusted closes matched the existing provider's factors within 0.000016% relative error; five met the existing model's technical eligibility checks. These are previously examined implementation diagnostics, not new forecasts, outcome evidence or promotion evidence. The 18 November alternative was published at 03:11 IST on 19 November and is ineligible for the 18 November information cutoff.

The prospective adapter keeps both existing fixed heads and ranking/financial rules. A separate public-only capture can run at 21:40 IST on trading weekdays. It records the immutable dataset revision, original URL, publication time, actual retrieval time, original-byte length and SHA-256. It also captures the original NSE session archive and trading calendar with their own actual retrieval clocks and hashes. It starts no new attempts after 21:58 and rejects captures completed after 22:00 IST. The worker can use a capture only when the artifact is ready in time. The existing 22:00 IST worker schedule is unchanged. A late, missing, stale, changed, ambiguous or future-dated snapshot is rejected. The preceding year's original data is also captured when the current year's history is too short for an overlap.

For a stale adjusted-provider series, the scoring-only path requires a hash-bound provider-history receipt captured no later than the information cutoff, at least 126 matching recent adjusted closes, no changed security identity or series, the pre-cutoff NSE archive and calendar, all intervening official session files with timely receipts, exact NSE OHLC and volume, consistent nonmissing alternative factors, a source-day factor consistent with its closing price and a gap of no more than five exchange sessions. The worker temporarily copies eligible pre-refresh histories into a disposable scoring area, so a later provider refresh cannot replace the earlier timed evidence; each temporary copy is hash checked before use. Cross-year gaps await a separately timed exchange calendar. A larger gap, missing timed receipt or source disagreement is left unresolved. The result is used in memory only for a new prospective score: it never replaces saved provider histories and cannot certify an entry, corporate-action interval, return, risk event or mature outcome. Both provider hashes, the original provider receipt clock and incomplete action status are stored with any new registered row. Old cohorts, probabilities, heads, baseline files and evidence receipts remain unchanged.

The source computes common split, bonus and cash-dividend adjustments but its documentation does not claim complete rights or merger/demerger adjustments. Source agreements do not establish a complete no-action interval. Any unresolved action still needs the original exchange/company notice and adjustment reconciliation before an outcome is verified. Actual coverage depends on source availability by 22:00 IST and all security-level checks; no coverage or accuracy gain is guaranteed.
